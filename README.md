# MagicStopWatch

A pixel-perfect clone of the iPhone native Stopwatch app with hidden magic features to force stop times and lap values.

## Features
- **100% Native Visuals**: Matches Apple Clock app's stopwatch screen.
- **Hidden Setup**: Triple-tap on the main timer to access settings.
- **Forced Stop**: Set a predefined value that appears when the spectator stops the timer.
- **Forced Laps**: Predefine a sequence of lap values.
